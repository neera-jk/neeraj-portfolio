# Neeraj Kumar — Portfolio

Personal portfolio site built with React, Vite, and Framer Motion.

## Stack

- React 19 + Vite
- Framer Motion for animations
- Plain CSS with CSS custom properties
- Canvas API for the star background

## Structure

- `src/components/` — one file per section (Hero, About, Experience, Skills, Projects, Education, Contact)
- `src/styles/` — one CSS file per component
- `public/` — static assets (resume, favicon, avatar)

## Running locally

```bash
npm install
npm run dev
```
